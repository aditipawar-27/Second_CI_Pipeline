# Second_CI_Pipeline

## About the Project
This repository contains Python programming assignments with corresponding test cases using **Pytest**.

The main objective of this project is to understand Python programming, write test cases, and implement a basic Continuous Integration (CI) workflow.

- Pytest
- Git
- GitHub

## How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/aditipawar-27/Second_CI_Pipeline.git
```

### 2. Open the Project Folder

```bash
cd Second_CI_Pipeline
```

### 3. Install Pytest

```bash
python -m pip install pytest
```

### 4. Run a Specific Test File

Example:

```bash
python -m pytest test_40_gcd.py -v
```

### 5. Run All Test Cases

```bash
python -m pytest -v
```
